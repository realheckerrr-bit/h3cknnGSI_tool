# h3cknnGSI_tool

Universal Android GSI Builder for Linux

**Features:**
- Supports multiple Android bases: Evolution X, Pixel Experience, One UI, ColorOS, HyperOS
- Pixel-style tweaks: Launcher, SetupWizard, Pixel props
- GApps baked directly into system.img
- Works on Treble devices
- Fully automated build pipeline on Linux
